Karta pracy

Runda 1: Prompt był dość ogólny, więc format zapisu notatek nie był dokładnie określony.

Runda 2: Po dodaniu wymagań dotyczących formatu notatki były zapisywane w jednym pliku.

Runda 3: Jeden przykład pomógł lepiej określić wygląd wpisu.

Runda 4: Trzy przykłady pozwoliły dokładniej pokazać oczekiwany format i sposób zapisu polskich znaków.

Runda 5: AI zaproponowało poprawioną wersję promptu, która dokładniej opisywała wymagania.

Obsługa błędów
Czas pracy: około 30 minut.
Najtrudniejsze: znalezienie miejsca w kodzie odpowiedzialnego za zapis notatek.
Wprowadzone zmiany: dodanie obsługi błędu, aby w razie problemu z zapisem pojawiał się odpowiedni komunikat.
Wynik: aplikacja powinna informować o błędzie zamiast po prostu przerywać zapis.
Wnioski

Dokładny opis zadania i przykłady pomagają uzyskać lepszy wynik. Ważne jest również sprawdzanie plików tworzonych przez aplikację i obsługiwanie błędów, które mogą pojawić się podczas zapisu.
